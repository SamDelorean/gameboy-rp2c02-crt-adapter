# Clone PPU Notes

This page is reserved for accumulating device-specific notes as clone PPUs are identified, sourced, or tested.

## Candidate families currently noted

- UMC UA6528
- WDL6528 family
- GS87008 family
- other discrete Famiclone-era PPUs discovered during sourcing

## Important distinction

The project is interested primarily in **discrete NTSC PPU-compatible parts with externally accessible pins**, not in generic NOAC/COB systems where the PPU is integrated and the required EXT/control interface may be inaccessible.

## Data to capture for every candidate

- top marking / manufacturer,
- package,
- donor board/console,
- region,
- pinout,
- supply voltage,
- master clock,
- EXT pin accessibility,
- register compatibility,
- palette behavior,
- composite-output behavior,
- visual differences versus a reference RP2C02,
- final project compatibility status.

All untested parts remain candidates only.
